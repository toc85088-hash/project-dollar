# 網站功能需求

更新日期：2026-08-24

## Priority Definition

- P0：本機 prototype 與正式發布前必須有
- P1：內容開始累積後應有
- P2：有讀者與轉換資料後再評估

## P0 — Prototype / Launch Foundation

### Content and Navigation

- Home 與 AI Automation、Workflows、AI Tools、Tutorials、Comparisons、Templates、Blog hubs。
- About、Contact、Privacy Policy、Terms、Affiliate Disclosure。
- 共用 header/footer、鍵盤可操作導覽、skip link、visible focus。
- 支援文章 detail page、breadcrumb、updated date、related links 與 CTA。
- 品牌名稱與 site URL 集中設定，避免逐頁替換。

### SEO

- 每頁唯一 title、meta description、canonical 與 Open Graph metadata。
- Article、Organization、Breadcrumb structured data 只描述頁面上可見且真實的資訊。
- 自動生成 `sitemap.xml` 與 `robots.txt`。
- 語意化 heading hierarchy、clean URLs、descriptive link text 與 image alt。
- 未核准正式網域時使用本機 URL；不得把示例網址當正式 canonical 上線。

### Accessibility

- 以 WCAG 2.2 AA 為設計目標；正式發布前需人工 audit。
- 完整鍵盤操作、清楚 focus、合理對比、表單 label 與錯誤訊息。
- 不以顏色作唯一訊號；支援 reduced motion；touch target 適合行動裝置。
- 裝飾圖片使用空 alt；資訊圖片使用描述目的的 alt。

### Performance and Resilience

- Mobile-first responsive layout，不依賴大型 client-side JavaScript 才能閱讀。
- 優先靜態／server-rendered content，控制字型、圖片與第三方 script。
- 圖片設定尺寸、使用現代格式與 lazy loading（首屏關鍵圖例外）。
- 對第三方分析、廣告或 affiliate script 設 performance budget。
- 明確 404 頁面；外部服務失敗不能阻擋文章閱讀。

### Editorial Safety

- Draft 不自動發布。
- 支援 status：draft、needs-review、verified、published、needs-update。
- 文章可記錄 evidence、testing scope、screenshots、claims requiring verification 與 last reviewed date。
- Comparison/review 在 verified 前不得顯示為正式推薦。

### Privacy and Security

- 不把 API key、token、客戶資料或付款資料提交到 repository。
- 表單需防垃圾訊息、驗證輸入並顯示 privacy notice；prototype 不收集／傳送資料。
- 正式網站只使用 HTTPS，依實際服務設定 security headers 與 cookies。
- Analytics、email、ads 只有在隱私頁、consent 與區域要求完成後才能啟用。

## P1 — Content Operations

- Markdown／MDX 或 CMS 文章流程，front matter schema 與 build-time validation。
- Topic、content type、updated date 與 verification status filters。
- RSS feed、站內搜尋、broken-link checker、image optimization pipeline。
- Editorial checklist、preview URL 與人工 publish approval。
- 內容更新提醒；工具與價格頁優先排入複查。

## P2 — Revenue and Product Validation

- 可追蹤但尊重隱私的 affiliate link management。
- 免費 template 下載與 email opt-in（需 consent、provider 與法律審核）。
- 數位商品 checkout 只在人工選定供應商與完成政策後整合。
- AdSense code 僅在網站內容與政策 readiness 通過人工審核後安裝。

## Explicitly Out of Scope Now

- 自動發布 AI 文章
- 帳號登入、付款、付費 SaaS、網域購買或 production deployment
- AdSense 申請／code installation
- 自動發送 email 或把表單資料傳到第三方
- 未經測試的即時 personalization 或 AI chatbot

## Acceptance Criteria

- `pnpm build` 與 `pnpm lint` 成功。
- 本機首頁及所有 required routes 回應 200；未知路徑回應 404。
- sitemap、robots、canonical、OG 與 JSON-LD 可由自動檢查確認。
- 360px 寬度無水平捲動，鍵盤能到達所有互動元件。
- 所有 placeholder email/domain/brand status 在正式發布前有明確阻擋標記。
- 人工完成內容、法律、隱私、SEO 與 accessibility 最終審查。
