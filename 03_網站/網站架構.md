# 網站架構

更新日期：2026-08-24

## 架構目標

網站以讀者任務而非工具品牌分類。每個主要 topic cluster 有一個穩定 hub，文章從 hub 向具體 workflow、tutorial、comparison 與 template 延伸，並透過上下層連結避免孤立頁面。

## URL Rules

- Lowercase ASCII、以短橫線分隔、無日期與 `.html`。
- URL 反映內容類型：`/workflows/...`、`/tutorials/...`、`/comparisons/...`、`/templates/...`。
- 文章換分類時優先保留既有 URL；必要變更使用單一 301 redirect。
- 不把工具價格、年份或「best」塞入 URL，除非是內容永久必要部分。
- Query parameters 不作為可索引內容的 canonical。

## Internal Linking Rules

每篇可索引文章至少要有：

1. Breadcrumb 回到 Home 與對應 hub。
2. 內文前半段連到一個必要背景頁。
3. 內文後半段連到一至三個相鄰解法或比較頁。
4. 結尾 CTA 連到下一個合理行動（template、tutorial 或相關 workflow）。
5. Hub page 回鏈所有納入 cluster 的已發布 supporting pages。

Anchor text 要描述目的頁，不重複堆疊完全相同關鍵字。未發布頁不建立連結，不建立空 placeholder 頁。

## Page Templates

- Hub：定位摘要、讀者選擇器、featured foundation、主題分組、最近更新。
- Article：breadcrumb、H1、dek、author/review/updated、quick answer、body、evidence notes、related reading、CTA。
- Tutorial：prerequisites、time/effort（需驗證）、steps、screenshots、test、rollback、maintenance。
- Comparison：methodology、who each tool suits、feature evidence、limitations、pricing checked date、verdict by scenario。
- Template：preview、適用情境、使用方式、版本、download／copy CTA、privacy note。

## Sitemap Inclusion

只收录 canonical、可索引、回應 200 且內容完整的頁面。排除草稿、測試路徑、搜尋結果、參數版本、空分類與尚未人工核准的 placeholder。
