# Research Checklist 02 — How to Automate Repetitive Tasks

對應 brief：`02-automate-repetitive-tasks.md`  
狀態：Research/testing not started。

## Claims requiring verification

- Repetitive task suitability criteria、risk classification 與 human-review guidance。
- Setup steps、required permissions、error handling、logs、retry、export 與 manual fallback。
- 任何 speed、time saved、error rate、ease-of-use 或 maintenance claim。
- Product plan、integration availability、regional availability、privacy/security 與 data retention。

## Tools requiring testing

- 選一個真正可取得的 representative no-code automation platform；先記錄選擇理由，不因 affiliate eligibility 選擇。
- 使用實際 plan 與 non-production account 測 trigger、action、AI step（若需要）、approval、logging、failure recovery、pause／disable 與 export。

## Pricing requiring verification

- Official pricing、included tasks／operations、AI usage、premium integration、trial、overage、tax、cancellation。
- 發布當日重新查核；清楚註明 plan、market、currency、billing interval 與 checked date。

## Screenshots needed

- Repetitive-task inventory、one-page workflow map、test-case log。
- 實測產品的 trigger/configuration、test result、error/log、pause/disable 畫面。
- 不用 vendor marketing screenshot 假裝 hands-on；所有 account details 必須遮蔽。

## Workflow test needed

- 一個完整且低風險的 dummy workflow，例如 fictional form submission → validation/category → review queue。
- 測 normal、missing、duplicate、bad format、permission failure、downstream failure 與 retry duplication。
- 比較完整 manual workload 與 automated workload，包含 setup、review、correction、maintenance。

## Affiliate opportunity

- Medium；實測平台可能有機會。
- 必須先有 active relationship、鄰近 disclosure 與 `rel="sponsored"`；推薦結論不能因 program 改變。

## Internal links

- `/ai-automation`、`/workflows`、`/tutorials`、`/templates`。
- 發布後連到 email／lead follow-up 等實測 workflow；未發布頁面不連結。

## External evidence required

- Vendor official setup、permissions、integration、billing、security/privacy、retention、export 與 status documentation。
- 涉及個資／consent 的適用監管或政府來源；需按讀者 market 限定。

## What cannot be claimed without first-hand testing

- Platform「no-code」「easy」「fast」「reliable」在目標 workflow 的實際含義。
- Exact setup time、steps、error recovery、usage cost、maintenance 或 savings。
- Integration 實際可用、AI output 可接受、approval gate 有效。

## Publication stop gate

- 沒有 reproducible workflow、failure evidence、current pricing check、screenshots 與 human approval，不得發布 tutorial 或 affiliate CTA。
