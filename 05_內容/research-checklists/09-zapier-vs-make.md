# Research Checklist 09 — Zapier vs Make

對應 brief：`09-zapier-vs-make.md`  
狀態：**BLOCKED — 兩個產品尚未在相同 current plans／workflows 下真實測試。**

## Claims requiring verification

- Pricing、task/operation usage model、AI features、integrations、limits、team/admin、logs/retry、support、security/privacy、export/cancellation。
- Ease、setup time、workflow readability、performance、reliability、error recovery、maintenance、value 與 final verdict。
- Plan/region/date、account eligibility 與 affiliate relationship。

## Tools requiring testing

- Zapier 與 Make 的真實 current accounts/plans；選擇公平且與 target reader 相關的可取得方案。
- 兩邊都建立同樣兩個 workflows，使用相同 fictional inputs、expected outputs、edge/failure cases。
- 測 onboarding、permissions、build/debug、human approval、run history、retry/duplicate、pause/export/delete/cancel path。

## Pricing requiring verification

- Official price、billing interval、minimum seat、task/operation counting、premium apps/modules、AI usage、overage、trial/free limits、tax、refund/cancellation。
- 建立可重算 usage examples，不把 tasks 與 operations 當同一單位；發布日重新查核。

## Screenshots needed

- Side-by-side workflow maps、相同 input/output、step/module count。
- 兩者 build UI、test run、history/log、error/retry、usage counter、permissions、export/disable/cancel evidence。
- Screenshot 標記 plan/date，不顯示 credential、email、workspace ID 或付款資料。

## Workflow test needed

- Workflow A：fictional form/enquiry → validation/category → review queue。
- Workflow B：fictional structured record → draft/follow-up preparation → human approval，不外寄。
- Edge cases：missing、duplicate、bad format、downstream unavailable、rate/usage limit、permission revoked、retry。
- 記錄 build/review/maintenance，不能只計成功 run speed。

## Affiliate opportunity

- High but relationship currently none。
- 兩邊使用相同 disclosure/CTA treatment；commission 不影響 verdict。Program status/terms 由 owner 真實確認。

## Internal links

- `/comparisons`、`/ai-tools`、`/workflows`、`/tutorials`、`/affiliate-disclosure`。
- 發布後可連 repetitive-tasks tutorial，前提是 scenario/evidence 已發布。

## External evidence required

- Zapier/Make official pricing, usage counting, product/integration, AI, security/privacy, status/support, export/delete/cancellation docs。
- 任何第三方可靠性或市場統計需 primary methodology；本站 test result 只代表記錄的 scenario/date。
- Current affiliate program terms 需 owner check；沒有 approval 不建立 links。

## What cannot be claimed without first-hand testing

- 哪個更容易、更快、更可靠、更便宜、更適合 small business 或是 winner。
- 實際 step count、usage consumption、debug/retry、integration quality、support、export/cancellation experience。
- 兩者功能相等、plan equivalent 或 total cost conclusion。

## Publication stop gate

- Same two workflows、same edge cases、current plans/pricing、side-by-side evidence、fact check、human verdict approval 未完成前維持 **BLOCKED**。
