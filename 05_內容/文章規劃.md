## Workflow

1. **Validate:** 人工確認 intent、SERP、目標市場用詞、內容差異與可取得證據。
2. **Brief:** 核准 primary keyword、purpose、outline、internal links、evidence 與 CTA。
3. **Research:** 優先官方文件；記錄 URL、作者／組織、發布／更新日期、accessed date 與支持的 claim。
4. **Test:** 在乾淨測試帳號和非敏感資料完成可重現步驟；保存環境、方案、日期、結果與限制。
5. **Draft:** 先直接回答問題，再說適用性、步驟、風險、檢查與維護。
6. **Edit:** 移除 hype、重複、無來源數字與暗示 first-hand 卻無證據的措辭。
7. **QA:** 事實、截圖、links、metadata、schema、mobile、accessibility、affiliate disclosure。
8. **Human publish:** 由指定人員簽核後才能發布；任何 automation 只能建立草稿。
9. **Maintain:** 依工具／價格變動風險排程複查，實際變更才更新 `dateModified`。

## Definition of Done

- [ ] Search intent 與角度經人工確認
- [ ] 沒有 keyword stuffing 或為字數而加的段落
- [ ] 每個外部 factual claim 有可靠來源與查核日期
- [ ] First-hand／tested 用語有測試紀錄支持
- [ ] 所有截圖來自授權來源、無個資且仍符合現行介面
- [ ] 至少一個 hub link、一個相關內容 link 與一個 next-step CTA
- [ ] Affiliate relationship 在 link 前後合適位置清楚揭露
- [ ] Title、description、canonical、OG 與 schema 正確
- [ ] 手機、鍵盤、links 與 spelling 完成 QA
- [ ] Editor 與 final human reviewer 已簽核

## Review Cadence

- Tool comparisons／pricing：高變動風險，至少每季檢查，遇到產品公告提早處理。
- Tutorials／screenshots：每 6 個月或重大 UI 變更時檢查。
- Evergreen frameworks：每 12 個月檢查，除非新風險或讀者回報。
- Legal／privacy claims：交由合格人士依市場與服務變更重新審閱。

以上為編輯排程，不代表資料仍正確；每次更新都要重新驗證來源。

## Conversion Principles

- 主要 CTA 應接續讀者任務，例如下載 workflow map、閱讀 implementation tutorial 或比較合適工具。
- Affiliate link 不是預設 CTA；只有在工具自然成為下一步且已完成測試／揭露時使用。
- 免費 template 用來驗證需求，付費商品只在讀者訊號與品質足夠後建立。
- 不用假倒數、虛構稀缺、誤導按鈕或遮擋內容的廣告。
