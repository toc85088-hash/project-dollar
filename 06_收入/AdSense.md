# Google AdSense 策略

更新日期：2026-08-24
狀態：**尚未申請、尚未安裝 AdSense code**

## Role

AdSense 是未來的輔助收入，不是建站初期的內容決策中心。優先完成足量的原創實用內容、信任頁面、導覽與技術品質，再由使用者本人檢查當時的官方政策並決定是否申請。

## Preconditions

- 網站使用正式 HTTPS 網域且可公開瀏覽。
- 已發布的頁面都有完整內容，沒有空分類、AI skeleton 或 lorem ipsum。
- About、Contact、Privacy Policy、Terms、Affiliate Disclosure 可見且經人工審閱。
- 內容原創、有明確作者／編輯責任，review 與 comparison 有真實測試證據。
- 行動裝置、導覽、broken links、sitemap、Search Console 與 analytics 基礎完成。
- 由人工檢查最新 AdSense program policies、隱私與 consent 義務。

## Placement Principles (Future)

- 廣告不得冒充導覽、download、next step 或產品推薦。
- 不用會遮住主要內容、造成 layout shift 或干擾行動閱讀的配置。
- Tutorial steps、比較表與 CTA 周圍保留足夠區隔，避免誤點。
- 設定 performance budget，觀察 LCP、INP、CLS 與讀者行為後才調整。
- 廣告數量服從內容品質與使用者體驗，不追求最大密度。

## Prohibited Actions

- Codex 不登入 Google 帳號、不送出申請、不接受條款、不建立付款設定。
- 不點擊自己的廣告、不要求他人點擊、不購買可疑流量。
- 不在 placeholder、copied、thin、fake review 或 prohibited content 頁面放廣告。
- 不在未完成 consent／privacy review 前載入相關 tracking 或 advertising code。

## Human Decision Gate

1. 逐項完成 `ADSENSE_READINESS.md`。
2. 人工確認最新官方規則與適用市場的 consent／privacy 要求。
3. 使用者本人核准並申請。
4. 只有核准後才建立 code installation 工作，並先在測試環境 QA。
